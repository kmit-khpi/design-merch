# Мерч і обкладинки КМІТ

**Автор:** ст. викл. С. В. Носко — приклад для ШІ-лабораторії КМІТ
**Напрям:** 2. ШІ-дизайн
**Посилання:** https://kmit-khpi.github.io/design-merch/

## Що це

Макети чашки, футболки та обкладинки для Reels/TikTok з символікою КМІТ. Кожне зображення — один промпт у Gemini (студентська підписка Google AI). Промпти наведено на сторінці.

## Як зроблено

- **Інструменти ШІ:** Gemini (генерування зображень).
- **Що перевірено:** усі написи кирилицею правильні. На обкладинці ШІ додав декоративні іскри, хоча просили без вогню, — залишено як приклад того, що результат треба перевіряти.
- Макети не є файлами для друку: для друку дизайн перемальовують у векторі.
